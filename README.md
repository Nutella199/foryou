# foryouMLOML

An interactive, mobile-friendly confession letter built with plain HTML, CSS, and JavaScript.

## Personalize the letter

Open `script.js` and edit the `LETTER` object at the very top:

- `recipient`: your crush's name
- `sender`: your name
- `paragraphs`: the final confession, split into readable paragraphs

## Preview locally

No install is needed. Run this in the project folder:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
